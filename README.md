# Image Processing Fundamentals

Python assignment applying basic image processing techniques to a photograph
using OpenCV, NumPy and Matplotlib.

## Techniques covered
1. Loading an image and reading its properties
2. Grayscale conversion
3. Negative and gamma transformation (0.5, 1.0, 2.0)
4. Linear contrast stretching and histogram equalization
5. Gaussian smoothing (3x3 and 7x7)
6. Sobel edge detection

## Run it
pip install -r requirements.txt
python assignment.py

The report with outputs and observations is in the PDF in this repo.
